# Milestone 2 - Application, objectives and user stories

PrismPM is a project-management workspace with a memory. It combines Tasks, Milestones, Dependencies, Risks, People, Evidence, Decisions, Activity History and an AI Assistant in one Project-scoped system.

## Objectives

1. Give a team one reliable place to plan and execute a Project.
2. Preserve the reasoning and source Evidence behind important Decisions.
3. Help Project Managers recover context quickly during handovers and changes.
4. Automate repetitive project-management work without allowing the model to silently make consequential changes.
5. Surface the effects of changed or broken Assumptions on downstream Decisions.

## Major user stories

- As a Project Manager, I want to create Projects, Tasks, Milestones, Dependencies and Risks so that I can plan and monitor work.
- As a Project Manager, I want to upload or paste Evidence and link it to project items so that important context is not lost.
- As a Project Manager, I want to record a Decision with citations, alternatives and Assumptions so that the team can understand its reasoning later.
- As a Project Manager, I want to ask “Why did we...?” and receive a concise answer with links to the recorded sources.
- As a Project Manager, I want the Assistant to create or update project items from natural language while retaining ownership checks, validation, History and approval boundaries.
- As a Project Manager, I want newly discovered Decisions to appear as proposals that I can edit, accept or reject before they enter the Decision Memory.
- As a Project Manager, I want to see when a changed Project fact breaks an Assumption and which downstream Decisions may be affected.
- As a team member or Participant, I want to communicate in the Project context without losing the relationship between conversation and work.
