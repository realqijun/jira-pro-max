# Milestone 2 - Application, objectives and user stories

PrismPM is a project-management workspace with a memory.
It combines Tasks, Milestones, Dependencies, Risks, People, Evidence, Decisions, Activity History and an AI Assistant in one Project-scoped system.
Meeting notes and files go in as Evidence; the Assistant reads them, proposes the Decisions, Tasks and Milestones they record, and answers "why did we...?" from the Decisions the PM confirmed, with a link to the source.

## Objectives

1. Give a team one reliable place to plan and execute a Project.
2. Preserve the reasoning and source Evidence behind important Decisions.
3. Turn meeting notes into structured work without retyping them, while the PM stays the one who confirms it.
4. Help Project Managers recover context quickly during handovers and changes.
5. Automate repetitive project-management work without allowing the model to silently make consequential changes.
6. Surface the effects of changed or broken Assumptions on downstream Decisions.

## Major user stories

**Planning and execution**

- As a Project Manager, I want to create Projects, Tasks, Milestones, Dependencies and Risks so that I can plan and monitor work.
- As a Project Manager, I want to see work on a board, a list, a Timeline and a Calendar so that I can plan at the level of detail the moment needs.
- As a new User, I want a sample Project and a short product tour on first sign-in so that I can see a working Project before I build my own.

**Capturing reasoning**

- As a Project Manager, I want to upload or paste Evidence (notes, transcripts, PDFs, Word files) and link it to Tasks, Risks and Milestones so that important context is not lost.
- As a Project Manager, I want to record a Decision with citations, alternatives and Assumptions so that the team can understand its reasoning later.
- As a Project Manager, I want the Decisions, Tasks and Milestones in my meeting notes to appear as Proposals with the exact sentence they came from, so that I can accept, edit or reject each one instead of retyping it.

**Retrieving reasoning**

- As a Project Manager, I want to ask "Why did we...?" and receive a concise answer with links to the recorded sources, or be told plainly that no Decision was recorded.
- As a Project Manager taking over a Project, I want to search Evidence by meaning and by Label so that I can find what the previous PM knew.
- As a Project Manager, I want to see when a changed Project fact breaks an Assumption and which downstream Decisions may be affected.

**Acting through the Assistant**

- As a Project Manager, I want the Assistant to create or update project items from natural language while retaining ownership checks, validation, History and approval boundaries.
- As a Project Manager, I want to approve every change the Assistant makes before it runs, with the exact target named, and to "always allow" the ones I trust.
- As a Project Manager, I want to draft a concept image of what the Project delivers from the brief I already uploaded, so that stakeholders have something concrete to react to.
- As a developer on the team, I want to drive my Projects from Claude Desktop or Cursor over MCP so that I do not have to switch tools.

**Collaboration**

- As a team member or Participant without an account, I want to communicate in the Project context through an invite link so that conversation stays attached to the work.
