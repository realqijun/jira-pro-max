# Milestone 4 - Target users and acquisition

## Target users

Our initial target users are Project Managers and small project teams running recurring or context-heavy Projects. Examples include implementation teams, operations teams, student project teams and agencies that repeatedly use a similar workflow but still need to adapt it to each client or Project.

The strongest early-adopter profile is a Project Manager who:

- manages several Projects or handovers at once;
- spends time reconstructing decisions from meetings, comments and files;
- wants AI assistance but needs citations and human control;
- is willing to experiment with a research preview and provide workflow feedback.

The product is less suitable initially for users who only need a simple personal checklist or a fully autonomous agent with no approval step.

## Acquisition plan

1. Start with direct outreach to Project Managers in our network and ask them to run one real recurring workflow.
2. Use those sessions to identify repeated templates, missing integrations and the questions users ask during handover.
3. Publish short demonstrations showing a source Evidence becoming a reviewed Decision and then producing an impact alert.
4. Share the research preview through university, builder and project-management communities.
5. Use the landing-page CTA and privacy-conscious PostHog funnel to measure visits, sign-ups, first Project creation, Evidence creation and Assistant usage.

The first success metric is not raw sign-ups. It is whether a new user completes one end-to-end memory workflow and returns to retrieve a Decision later.
