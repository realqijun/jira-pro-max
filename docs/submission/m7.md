# Milestone 7 - Use of LLMs

PrismPM uses LLMs where language understanding and flexible interaction provide clear value:

1. **Natural-language Assistant:** The model interprets a Project Manager's request, selects read or write tools, observes their results and explains what changed.
2. **Proposal extraction:** The model reads Evidence and Comments and proposes structured Decisions, including citations, alternatives and supported Assumptions.
3. **Why-did-we answers:** Deterministic search retrieves recorded Decisions and their citations; the model turns that result into a concise answer without inventing a reason when no Decision exists.
4. **Reflection:** After eligible conversations, the model updates versioned User Profile and Project Working Memory documents.
5. **Context-aware planning:** The Assistant can create a sequence of Milestones and Tasks using the Project's existing People, statuses and dates.

LLMs are suitable because Project work is expressed in natural language, source material is unstructured, and users want to interact with several related entities in one request. They are not used for everything: authorization, ownership, validation, transactions, Activity History, Decision search and impact detection remain deterministic application logic.

This separation is intentional. The model proposes interpretations and tool calls, while the application remains the source of truth and enforces permissions, confirmation boundaries, citations and durable state.
