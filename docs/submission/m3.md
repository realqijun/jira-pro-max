# Milestone 3 - Secret sauce and moat

Our moat is not the use of an LLM. Models and basic chat interfaces are increasingly commoditized, so a competitor could clone a superficial version of PrismPM quickly.

Our defensibility comes from making **traceable project memory** the core data model and workflow:

1. **Structured decision graph:** PrismPM connects Decisions to Evidence, citations, Assumptions, superseded Decisions, Tasks and downstream impact. This is more useful than storing a chat transcript because the information remains queryable and actionable.
2. **Evidence-grounded automation:** The Assistant and proposal extractor operate on project-scoped data, use structured outputs, and require citations. A proposal does not become an accepted Decision until a human reviews it.
3. **Accumulating project history:** Each completed Project creates a richer history of decisions, changes, assumptions and outcomes. Over time this produces high-value organizational context that is difficult to recreate by importing a task list into a new competitor.
4. **Workflow fit and trust:** Writes go through the same authorization, validation, transaction, Activity History and approval boundaries as normal UI actions. This makes the AI useful in serious workflows without treating the model as an unrestricted administrator.
5. **Interoperability:** The same capabilities are available through the web Assistant and MCP, so teams can use PrismPM from their existing AI clients while keeping the authoritative Project state in PrismPM.

Our strategy is to focus on teams managing recurring, context-heavy Projects and accumulate high-quality, user-approved Decision Memory. We would strengthen this moat through importers, reusable workflow templates, organization-level taxonomies, outcome feedback and increasingly accurate retrieval based on each team's vocabulary. Privacy, exportability and per-user provider credentials are important because the moat should be trust and workflow value, not lock-in through inaccessible data.
