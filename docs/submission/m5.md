# Milestone 5 - MVP and future expansion

## MVP

The MVP contains the smallest coherent loop from planning to remembered reasoning:

1. **Project management:** Projects, Tasks, Milestones, Dependencies, statuses, Risks and People.
2. **Evidence:** Pasted notes, uploaded files and transcripts stored in Project context.
3. **Decision Memory:** Decisions with citations, alternatives, Assumptions, supersession and Activity History.
4. **AI Assistant:** Project-scoped natural-language reads and writes through validated tools, with approval for destructive or Project-level changes.
5. **Proposal workflow:** Extract possible Decisions from Evidence, then let a Project Manager edit, accept or reject them.
6. **Impact awareness:** Detect broken Assumptions and show affected downstream Decisions.
7. **Collaboration and access:** Authentication, Project ownership, Participant messaging and safe file access.
8. **Operational basics:** Responsive workspace UI, landing page, analytics, testing and deployable PostgreSQL-backed infrastructure.

## How we selected these features

We prioritized features that complete the core problem loop:

**capture source material -> structure the current work -> preserve a Decision -> retrieve the reasoning -> react when assumptions change.**

Generic views and decorative automation were secondary. A feature was included when it either supports that loop, creates trust in AI actions, or is necessary for a usable multi-user Project.

## Future features

- Reusable Project and workflow templates.
- Importers for existing task tools, documents and meeting platforms.
- Calendar, email and chat integrations.
- Team-level permissions and organization workspaces.
- Better retrieval, source ranking and configurable model routing.
- Health briefings and proactive summaries based on the deterministic Project read model.
- Outcome feedback linking Decisions to delivery results.
- Usage-based or team-based billing and enterprise controls.
