# Milestone 0 - Problem

Project teams do not only need to remember _what_ they agreed to do; they also need to remember _why_ they agreed to do it.

In a typical project, Tasks, Milestones, meeting notes, files, chat messages, Risks and Decisions are spread across different tools. A new Project Manager can see the current task list but often cannot recover the reasoning behind a Decision, the Evidence that supported it, or the Assumption on which it depended. When the project changes, the team must manually discover which downstream work is affected.

PrismPM solves this continuity problem by combining project management with a structured project memory. It keeps operational data such as Tasks, Milestones, People, Risks and Dependencies together with Evidence, Decisions, citations, Assumptions and change History. Its Assistant can read and update that shared context, while human approval remains required for consequential changes.

The product is especially useful for repetitive or long-running projects, where teams repeatedly perform similar workflows and where losing context during handovers creates avoidable rework.
